# RBI Isolated Browser — Slice A1 (Walking Skeleton) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove Remote Browser Isolation end-to-end on the existing guacd/VNC gateway pipeline: an `ISOLATED` site streams a containerized on-prem browser (opened at the site's internal URL) to the vendor, single concurrent session, Pro-gated off by default.

**Architecture:** New `accessMode=ISOLATED` reuses the VNC gateway path. A new `captivo-access-browser` container (Xvfb + Chromium-kiosk + x11vnc + a tiny process-control HTTP server) runs on the connector's `captivo-gateway` network. The manager descriptor returns a VNC target pointing at that container plus a `navigateUrl`; the data-plane `guac-tunnel` navigates the browser (via a connector-relayed control call) then relays the VNC stream through guacd. Session UI, audit, and recording are reused unchanged.

**Tech Stack:** Next.js/Prisma 7 (manager), Go (data-plane), Docker (browser image), vitest + `go test`.

## Global Constraints

- **English only** — code, comments, commit messages. **No Claude signature.**
- **Additive only:** TRANSPARENT and GATEWAY behavior is unchanged (regression-test both).
- **Pro-gated:** `ISOLATED_ENABLED` env (default **off**), mirroring `src/lib/vault/enabled.ts` / `recordingEnabled()`. Keep off in prod until Slice A2.
- **Single concurrent ISOLATED session in A1** — a data-plane single-flight guard rejects a 2nd concurrent session (prevents a shared x11vnc view = data leak). Real concurrency is A2.
- **No docker socket** anywhere. A1 uses one persistent browser container; navigate = process relaunch inside it (no CDP dependency).
- `sftp-root-directory` / vault: an ISOLATED site has **no VaultCredential**, `hostname = null`, and reuses `Site.upstreamUrl` as the URL to open.
- Ships as **v0.58.0** (schema + manager + dataplane + new browser image). Verify with `pnpm test`, `pnpm build` (capture exit code, never pipe to grep), and `go build`/`go test ./...` in `dataplane/`.

```python
#!/usr/bin/env python3
# Minimal in-container control for the isolated browser. Launches/relaunches a
# kiosk Chromium on DISPLAY :1. Internal-only (bind on the container network).
import os, shutil, signal, subprocess, urllib.parse
from http.server import BaseHTTPRequestHandler, HTTPServer

PROFILE = "/profile"
CHROME = shutil.which("chromium") or shutil.which("chromium-browser") or "chromium"
_proc = {"p": None}

def launch(url: str):
    kill()
    os.makedirs(PROFILE, exist_ok=True)
    _proc["p"] = subprocess.Popen(
        [CHROME, "--kiosk", "--no-first-run", "--no-default-browser-check",
         "--disable-translate", "--user-data-dir=" + PROFILE, url],
        env={**os.environ, "DISPLAY": ":1"})

def kill():
    p = _proc["p"]
    if p and p.poll() is None:
        p.send_signal(signal.SIGTERM)
        try: p.wait(timeout=5)
        except Exception: p.kill()
    _proc["p"] = None

class H(BaseHTTPRequestHandler):
    def _send(self, code, msg=b"ok"):
        self.send_response(code); self.send_header("Content-Length", str(len(msg))); self.end_headers(); self.wfile.write(msg)
    def do_GET(self):
        u = urllib.parse.urlparse(self.path)
        if u.path == "/navigate":
            q = urllib.parse.parse_qs(u.query).get("url", [""])[0]
            if not (q.startswith("http://") or q.startswith("https://")): return self._send(400, b"bad url")
            launch(q); return self._send(200)
        if u.path == "/healthz": return self._send(200)
        self._send(404, b"no")
    def do_POST(self):
        if urllib.parse.urlparse(self.path).path == "/reset":
            kill(); shutil.rmtree(PROFILE, ignore_errors=True); launch("about:blank"); return self._send(200)
        self._send(404, b"no")
    def log_message(self, *a): pass

if __name__ == "__main__":
    launch("about:blank")
    HTTPServer(("0.0.0.0", 7900), H).serve_forever()
```

```go
package main

import ("net/url"; "sync/atomic")

// buildNavigateRequest formats a minimal HTTP/1.0 GET to the browser control
// server's /navigate endpoint. The URL is query-escaped.
func buildNavigateRequest(host, target string) string {
	return "GET /navigate?url=" + url.QueryEscape(target) + " HTTP/1.0\r\n" +
		"Host: " + host + "\r\n" +
		"Connection: close\r\n\r\n"
}

// buildResetRequest formats the POST /reset control call.
func buildResetRequest(host string) string {
	return "POST /reset HTTP/1.0\r\nHost: " + host + "\r\nContent-Length: 0\r\nConnection: close\r\n\r\n"
}

// isoGuard is the A1 single-flight lock: only one ISOLATED session at a time
// (a 2nd concurrent x11vnc viewer would share the same display = data leak).
// Concurrency arrives in Slice A2 (per-session broker).
type isoGuard struct{ busy int32 }

func (g *isoGuard) tryAcquire() bool { return atomic.CompareAndSwapInt32(&g.busy, 0, 1) }
func (g *isoGuard) release()         { atomic.StoreInt32(&g.busy, 0) }
```

## Notes for the implementer

- A1 is a **skeleton**: one ISOLATED session at a time (single-flight guard). Do **not** remove the guard or ship `ISOLATED_ENABLED=1` to prod expecting concurrency — that lands in **A2** (per-session in-container process broker; no docker socket).
