# RBI Isolated Browser — Slice A3 (Clipboard Control + Recording) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an isolated-browser resource block clipboard copy-out (and paste-in) server-side, and confirm session recording works for it — closing RBI's main data-leak gap.

**Architecture:** Manager-only. The ISOLATED descriptor branch stops returning `params: {}` and instead maps the site's `clipboardMode` to guacd `disable-copy`/`disable-paste` via the existing `toGuacArgs`; the data-plane already forwards those params to guacd unchanged. The site form gains a Clipboard control for the ISOLATED type. Recording already works (data-plane records the guac stream) — verified at Gate A.

**Tech Stack:** Next.js/TypeScript (manager), vitest.

## Global Constraints

- **English only** — code, comments, commit messages. **No Claude signature.**
- **Manager-only** — no data-plane, browser-image, or schema change. `clipboardMode` is already stored/submitted/validated for ISOLATED (A1); this slice adds the descriptor mapping + the form control.
- **Additive** — TRANSPARENT and GATEWAY behavior unchanged.
- Ships as **v0.60.0**. Verify with `pnpm build` (capture exit, no grep pipe) and `pnpm test`.

### Task 1: Descriptor applies clipboard for ISOLATED (+ VNC test)

**Files:**
- Modify: `src/app/api/internal/gateway/descriptor/route.ts`
- Test: `src/lib/gateway/guac-params.test.ts`

**Interfaces:**
- Consumes: `toGuacArgs({}, clipboardMode, "VNC")` → `{}` / `{disable-copy}` / `{disable-paste}` / both (unchanged function).

- [ ] **Step 1: Add the VNC clipboard test (documents the exact ISOLATED params)**

In `src/lib/gateway/guac-params.test.ts`, inside the `describe("toGuacArgs", …)` block, add:

```ts
  it("VNC clipboard: maps clipboardMode to disable-copy/paste, nothing else", () => {
    expect(toGuacArgs({}, "allow", "VNC")).toEqual({});
    expect(toGuacArgs({}, "no_copy", "VNC")).toEqual({ "disable-copy": "true" });
    expect(toGuacArgs({}, "no_paste", "VNC")).toEqual({ "disable-paste": "true" });
    expect(toGuacArgs({}, "none", "VNC")).toEqual({ "disable-copy": "true", "disable-paste": "true" });
  });
```

- [ ] **Step 2: Run it — expect PASS**

Run: `pnpm test src/lib/gateway/guac-params.test.ts`
