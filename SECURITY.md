# Security Policy

Captivo Access is a security product; we take vulnerabilities seriously.

## Reporting a Vulnerability

**Do NOT open a public issue for security vulnerabilities.**

Email **security@captivo.io** with:
- A description of the vulnerability and its impact
- Steps to reproduce (proof-of-concept if possible)
- Affected version / commit

We aim to acknowledge within 72 hours and provide a remediation timeline
after triage. Coordinated disclosure is appreciated — please give us
reasonable time to patch before public disclosure.

## Supported Versions

Only the latest tagged release (`vX.Y.Z`) is supported — fixes land there, not in
older tags. The project is functional and used, but not yet formally
production-hardened; review the [Security model](./README.md#security-model) and
run your own assessment before relying on it.
